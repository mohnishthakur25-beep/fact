# fact

QuarantineCare — 74-Bed Virus Quarantine & Treatment Facility Tracker.

## Features
- **74-Room Live Map**: Track bed occupancy, daily workflow stage, and vacant rooms.
- **Nurse Station**: Daily temperature logging with duplicate-entry prevention.
- **Doctor Rounds**: Prioritized queue of temp-ready patients, 3-day fever-free streak tracking, and one-click discharge approval.
- **Admin & Discharges**: Instant bed release, new patient admission, and live **85% success / 15% mortality** quality benchmark monitoring.

## Run Locally
```bash
npm install
npm run build
npm start
```
Open `http://localhost:3001`.
